# Snelweg – progress

**Live:** https://kikonig.github.io/snelweg/ (repo: https://github.com/KiKonig/snelweg). Every push to `main` redeploys automatically.

> Working mode (user's wish, 21 Nov 2026): no milestone gating. Everything that exists is usable immediately; unfinished parts are hidden, not labelled "coming in milestone X". Build in the spec's order, but ship learnable content as early as possible.

## Done
**Skeleton** (v0.1.x)
- Vite + TypeScript + Preact + vite-plugin-pwa; Dexie (IndexedDB) storage; installable, offline
- 8 screens, bottom navigation, settings via gear icon, dark mode, safe areas
- Export / import / reset of progress; Dutch TTS with voice check (iPhone: silent mode mutes it – hint in Settings)
- GitHub Actions → GitHub Pages

**Learning core** (v0.2.0)
- Spaced repetition with FSRS (`ts-fsrs`), auto-grading by correctness + speed (median per exercise type), "no grinding" (3 correct in a row → easy)
- Daily session builder: ~70% due reviews + new material (pattern: phrase, phrase, verb); choose 10–60 min on Home; "Noch eine Runde" after each session; wrong items come back later in the same session
- Exercises: new-verb intro (full table + audio), conjugation drill incl. question form (inversion), gap sentences, "Sag es" (speaking, self-graded), listening (pick the meaning)
- Answer checking with explanations (inversion -t, Stamm + t, plural = infinitive, irregular, stem spelling) + "Meine Antwort war richtig"
- Mistake memory → summary shows top mistake with "Fehler jetzt üben"
- Practice by topic: any verb ("Dieses Verb üben"), any situation ("Diese Sätze üben")
- Content: 56 verbs (`content/verbs.json`, generated by `scripts/gen-verbs.mjs`, tables checked), 96 phrases in 9 situations, 6 grammar topics, 15 pronunciation sounds, 15 sound-shift rules, 22 false friends
- Library: verbs, grammar, pronunciation, sound rules, false friends – all with audio
- Dictionary: searches verbs, phrases, examples, false friends both ways (real 3,000-entry dictionary still to do)
- Progress: skills (verbs, sentence structure, speaking, listening), minutes per day, top mistakes

**Pronunciation** (v0.3.0)
- Pronunciation check (SPEC exercise 16, optional): browser speech recognition (nl-NL) → word-by-word comparison with the target (fuzzy LCS, digits → words, split/joined compounds), score + verdict, red/orange word marks, best of up to 5 recognizer alternatives (`src/speech.ts`)
- In "Sag es": speak into the mic first → answer is revealed with the score, and the matching self-grade is suggested (self-grading stays)
- Record yourself (MediaRecorder, works offline) → play yours and the model; last 20 recordings kept on device, deletable, excluded from export (`src/recorder.ts`)
- Mic tools also in new-phrase intros and on every phrase in Sprechen (🎤); settings toggle + dictation hint
- Not verified on a real iPhone yet (speech recognition in home-screen apps, audio routing after mic use)

## How to run on the computer
```
npm install
npm run dev       # development, http://localhost:5173/snelweg/
npm run build     # production build into dist/
npm run preview   # serve the build, http://localhost:4173/snelweg/
node scripts/gen-verbs.mjs   # regenerate content/verbs.json after editing the verb list
```
